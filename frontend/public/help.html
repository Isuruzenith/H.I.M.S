Demo Test Workflow

To evaluate how the database triggers, constraints, and web components interact, follow this typical operational cycle:

1

Direct Stock Issuing

Log in as **Inventory Manager** (`nuwan.inventory`) or other staff, and go to the **"Issue Stock"** page.

2

Database FIFO Allocation

Select a department and an item (e.g. Paracetamol), enter a quantity, and click **"Issue stock"**. The database stored procedure immediately runs the FEFO/FIFO batch reduction logic.

3

Procure Refill

Log in as **Procurement Officer** (`dinesh.procure`), view low stock reorders, generate a Purchase Order, and receive stock to replenish.

4

Analyze Analytics

Log in as **Hospital Admin** (`harsha.admin`) to view ABC demand curves, reorder rates, and generate analytical PDF reports.

System Role & Feature Specifications

🛡️ Admin Panel (`anjali.admin`)

Provides system configuration, settings adjustments, and hospital structure configurations.

  • Staff Onboarding: Create, update, or suspend user login credentials for clinical staff.
  • Department Directory: Create new hospital wings, wards, or labs (e.g., ICU, Pharmacy, Surgery).
  • Security Audits: Track overall registration patterns and account classifications.

📦 Inventory Management (`nuwan.inventory`)

Central console for overseeing item levels, batch details, and handling internal distributions.

  • Inventory Catalog: Add, edit, or search for medicines, consumables, and equipments.
  • Reorder Rules: Setup safety stock, reorder levels, and maximum thresholds for individual items.
  • Issue Approval: Accept/Reject internal department issue requests, causing automated batch reductions via SQL Server triggers.
  • Adjustment Logs: Manually adjust stock levels for items damaged or expired.

💊 Pharmacy & Medicines (`kavindi.pharma`)

Access pharmaceutical listings, manage generic formulas, and check storage conditions.

  • Generic Database: Track generic vs brand names, dosage details (e.g., 500mg, 10ml), and drug forms (vial, tablet, capsule).
  • Prescription Verification: Audit if prescription-required medications are flagged.
  • Storage Constraints: Set and check cold chain storage regulations (e.g. Refrigerate 2-8°C).

💼 Procurement & Purchasing (`dinesh.procure`)

Handles commercial interactions, manages suppliers, and creates stock acquisition orders.

  • Supplier Registry: Record contact details, addresses, lead times, and preferred statuses for vendors.
  • Purchase Orders (PO): Generate PO requests, track states (Pending, Approved, Ordered, Completed), and calculate costs.
  • Stock Intake: Reconcile ordered vs received item batches to automatically update system stock numbers.

🏥 Department Stock Requests (`malith.er`)

Enables general wards, ER, and ICU staff to source items from the main pharmacy.

  • Request Dashboard: Create requests for medicines or consumables indicating required quantities.
  • Request Status Tracking: Check if a request has been Approved, Issued, Rejected, or Cancelled.

📊 Business Intelligence & Reports (`harsha.admin`)

Aggregated operational reports, demand summaries, and SQL views-driven charts.

  • ABC Analysis: Categorizes items based on consumption value (A: High value, B: Moderate value, C: Low value).
  • Demand Categories: Classifies items into Fast Moving, Medium Moving, and Slow Moving groups.
  • Supplier Performance: View average lead times, delayed order ratios, and cost structures per vendor.
  • Operational Audit Log: Inspect complete historic transaction logs containing batch, user, and date fields.
